    HyperRun(hrun) 스크립트 / 변수 맵

    업데이트 (2026-06-21): C++ hrun을 순수 네트워크 라우터로 축소하는 리팩터링을 완료했습니다. 아래 변수 맵은 그 최종 상태를 반영합니다. 주요 변경:

    • C++ hrun → 순수 라우터. 네트워크 A/B 선택 + 네트워크 값 주입 + execv 만. 사용자명·데이터 디렉터리·서브커맨드 처리 제거 (403줄 → 약 195줄).
    • config/init을 릴리스 run_hrun으로 이전. config는 해석된 데이터 디렉터리만 출력(생성 안 함), init은 "removed" 안내.
    • core 디스패처 리네임: core/bin/run_hrun → core/bin/hrun-core (릴리스 러너 scripts/run_hrun과 이름 충돌 해소).
    • HYPERRUN_USER 완전 제거. 필수였지만 doctor/env 출력에만 쓰여 실효성이 없었음.
    • 동작 변화: 진단 커맨드(config/help/version)도 러너를 거치므로, 러너가 하나도 없으면(exit 127) 진단도 실행되지 않음.

    각 스크립트의 역할 / 선언(export)하는 변수 / 참조하는 변수를 정리한 문서입니다. (실행 체인 순서)

    실행 체인

    hrun (C++)  →  scripts/run_hrun (네트워크/릴리스 러너)  →  core/bin/hrun-core (core 디스패처)  →  command wrapper  →  real tool

    중간에 core/lib/*.sh는 디스패처·래퍼가 .(source)로 불러쓰는 라이브러리입니다.

    1. src/hrun/main.cpp — C++ 엔트리포인트 (/appl/bin/hrun)

    하는 일: 네트워크 A/B 선택(컴파일된 경로 기준) → 네트워크 값 주입 → 선택된 네트워크 run_hrun 으로 execv. 그게 전부입니다(순수 라우터). 사용자·데이터 디렉터리·서브커맨드는 다루지 않고 모든 인자를 그대로 넘깁니다.

    구분 변수
    선언(export) HYPERRUN_NETWORK(A/B), HYPERRUN_ROOT, HYPERRUN_RUNNER, API_KEY·BASE_URL(컴파일값, 비어있지 않을 때만)
    참조(read) HYPERRUN_TRACE / 컴파일 상수 HYPERRUN_RUNNER_A·B, HYPERRUN_ROOT_A·B, HYPERRUN_API_KEY_A·B, HYPERRUN_BASE_URL_A·B

    2. scripts/run_hrun — 네트워크/릴리스 러너 (RELEASE/bin/run_hrun = HYPERRUN_RUNNER)

    하는 일: HYPERRUN_ROOT 필수 검사 → 데이터 디렉터리 해석 → config/init 가로채기 → 표준 레이아웃 생성(tools/ commands/ desc/ docs/ env/ .hyperrun/) → core 디스패처(hrun-core) exec.

    구분 변수
    선언(export) HYPERRUN_DATA_DIR(해석된 절대경로)
    참조(read) HYPERRUN_ROOT(필수), HYPERRUN_DATA_DIR, HYPERRUN_DEFAULT_DATA_DIR, HOME / 경로조립: $HYPERRUN_ROOT/core/current/bin/hrun-core

    config → 해석된 data_dir와 존재 여부만 출력(디렉터리 생성 안 함). init → "removed" 안내 후 종료.

    3. core/bin/hrun-core — core 디스패처 ($HYPERRUN_ROOT/core/current/bin/hrun-core)

    하는 일: ROOT/DATA_DIR/NETWORK 필수 검사 → lib 4개 source → global/profile env 로딩 → 서브커맨드(help version doctor list which env docs --profile) 처리 → 명령 래퍼 탐색(user→system) → 컨텍스트 설정 후 래퍼 exec.

    구분 변수
    선언(export) HYPERRUN_ROOT,HYPERRUN_DATA_DIR(trim 재export), HYPERRUN_CORE, HYPERRUN_COMMAND_DIR_USER, HYPERRUN_COMMAND_DIR_SYSTEM, HYPERRUN_PROFILE, HYPERRUN_COMMAND_NAME, HYPERRUN_TOOL_ID, HYPERRUN_TOOL_HOME (+ env 파일이 export하는 값들)
    참조(read) HYPERRUN_ROOT·HYPERRUN_DATA_DIR·HYPERRUN_NETWORK(전부 필수), HYPERRUN_PROFILE, HYPERRUN_INSPECT(래퍼 탐색 시 describe/which/env/docs로 세팅), TMPDIR / VERSION·env·desc·docs 파일

    4. core/lib/*.sh — 라이브러리 (source 전용)

    파일 하는 일 선언(export) 참조
    common.sh hrun_die/log/is_valid_name/ensure_executable/require_env 유틸 없음(지역변수만) 없음
    env.sh env 파일 안전 파서(${VAR},${VAR:-def}만 허용) env 파일의 key=value를 동적 export env(현재 환경 전체)
    platform.sh OS 감지 HYPERRUN_OS_ID, HYPERRUN_OS_MAJOR, HYPERRUN_ARCH /etc/os-release, uname -m
    tool.sh hrun_enter_tool — 툴 홈 진입/생성 HYPERRUN_TOOL_ID, HYPERRUN_COMMAND_NAME, HYPERRUN_TOOL_HOME HYPERRUN_DATA_DIR

    5. command wrapper 예: toolkits/python/commands/python

    하는 일: lib source → hrun_enter_tool python → python/pip env 로딩 → OS별 파이썬·휠하우스 선택 → HYPERRUN_INSPECT 분기 → 실제 python exec.

    구분 변수
    선언(export) HYPERRUN_TOOL_*(enter_tool 경유), PYTHONNOUSERSITE, PIP_NO_INDEX, PIP_DISABLE_PIP_VERSION_CHECK, PIP_FIND_LINKS
    참조(read) HYPERRUN_CORE(필수), HYPERRUN_COMMAND_NAME, HYPERRUN_ROOT, HYPERRUN_DATA_DIR, HYPERRUN_OS_MAJOR, HYPERRUN_PYTHON_EXE, HYPERRUN_PYTHON_RHEL7/8/9, HYPERRUN_WHEELHOUSE(_RHEL7/8/9), HYPERRUN_INSPECT, PIP_FIND_LINKS

    핵심 흐름 한 줄 요약

    • 컴파일된 비밀/경로(NETWORK·ROOT·RUNNER·API_KEY·BASE_URL)는 오직 C++만 알고 주입.
    • 데이터 디렉터리(DATA_DIR)는 네트워크 run_hrun이 해석·초기화하고 config/init을 담당.
    • 명령/툴 컨텍스트(COMMAND_NAME·TOOL_ID·TOOL_HOME·OS·PROFILE)는 core 디스패처(hrun-core) + lib + wrapper가 책임.

    툴별 쓰기 홈은 HYPERRUN_TOOL_HOME = $HYPERRUN_DATA_DIR/tools/<tool_id> 하나뿐이며, 래퍼가 hrun_enter_tool 호출 시 lazy 생성됩니다. 툴 고유 HOME 변수는 env/tools/<tool>.env 에서 FOO_HOME=${HYPERRUN_TOOL_HOME} 식으로 매핑합니다.
