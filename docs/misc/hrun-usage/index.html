    HyperRun(hrun) 사용자 가이드

    폐쇄망에서 hrun으로 내부 도구를 실행하는 일반 사용자 관점의 가이드다. 여기서 다루는 모든 것은 내 데이터 디렉터리 안에서 일어나며, 시스템(글로벌) 영역은 건드리지 않는다. (글로벌 툴 추가는 관리자 가이드 참고.)

    기본 사용

    hrun <command> [args...]
hrun python -V
hrun pip list
hrun mycli a b c

    <command> 뒤 인자는 그대로 실제 도구로 전달된다.

    내 데이터 디렉터리

    내 모든 상태(HYPERRUN_DATA_DIR)가 들어가는 곳이다. 위치는 이 순서로 정해진다.

    1. 내가 지정한 절대경로 HYPERRUN_DATA_DIR
2. HYPERRUN_SHARED_DATA_ROOT/<user>/.hrun   (관리자가 컴파일로 켠 경우만)
3. $HOME/.hrun
    • 전부 일반 폴더다(심볼릭 없음). 권한은 기본값(umask)을 따른다.
    • 어디로 잡혔는지 확인:
    $ hrun config
data_dir=/home/me/.hrun
data_dir_exists=yes

    config는 경로만 보여주고 디렉터리를 만들지는 않는다. 실제 생성은 일반 커맨드를 처음 실행할 때 일어난다.

    레이아웃:

    $HYPERRUN_DATA_DIR/
  commands/            # 내 커맨드(시스템보다 우선)
  desc/  docs/         # 내 설명·문서
  env/                 # 내 환경변수 오버라이드
    global.env
    profiles/{user,agent}.env
    tools/<tool>.env
  tools/<tool_id>/     # 툴별 쓰기 공간(HYPERRUN_TOOL_HOME)
  .hyperrun/           # 세션·로그·캐시

    내가 쓰는 내장 커맨드

    hrun help                 # 사용법
hrun version              # core 버전
hrun doctor               # 진단(네트워크/경로/플랫폼)
hrun config               # 내 데이터 디렉터리 경로/존재여부
hrun list                 # 쓸 수 있는 커맨드 목록
hrun which <command>      # 실제 실행 파일 경로
hrun env <command>        # 그 커맨드의 환경 컨텍스트
hrun docs [--path] <command>   # 커맨드 문서

    내 커맨드 추가 (관리자 없이)

    관리자 권한이 없어도, 내 데이터 디렉터리에 실행 파일을 두면 바로 커맨드가 된다.

    cat > "$HYPERRUN_DATA_DIR/commands/hello" <<'SH'
#!/bin/sh
echo "hi from $HYPERRUN_USER"
SH
chmod +x "$HYPERRUN_DATA_DIR/commands/hello"

hrun hello

    탐색 순서가 사용자 → 시스템이라, 같은 이름이면 내 커맨드가 시스템 커맨드를 덮어쓴다. 설명/문서도 내 데이터 디렉터리에 둘 수 있다.

    $HYPERRUN_DATA_DIR/desc/hello.desc          # list에 뜨는 한 줄 설명
$HYPERRUN_DATA_DIR/docs/commands/hello.md   # hrun docs hello

    내 환경변수 오버라이드

    env 파일은 셸이 source 하지 않고 HyperRun이 안전 파싱한다. 내 데이터 디렉터리의 파일이 시스템 기본값을 덮어쓴다.

    # $HYPERRUN_DATA_DIR/env/global.env
KEY=value
KEY="value with space"
KEY='literal'              # 작은따옴표는 확장 안 함
KEY=${OTHER}/suffix
KEY=${OTHER:-default}

    $VAR, $(cmd), 백틱, 산술 확장 등은 거부된다. :-default 없는 미정의 ${VAR}도 에러라 오타를 일찍 잡아준다.

    로드 순서(뒤가 앞을 덮어씀):

    $HYPERRUN_ROOT/env/global.env              (시스템)
$HYPERRUN_DATA_DIR/env/global.env          (나)
$HYPERRUN_ROOT/env/profiles/<profile>.env  (시스템)
$HYPERRUN_DATA_DIR/env/profiles/<profile>.env (나)

    프로파일

    기본은 user. 다른 프로파일로:

    hrun --profile agent python job.py

    툴별 쓰기 공간

    도구가 쓰기 공간이 필요하면 툴 홈을 쓴다.

    HYPERRUN_TOOL_HOME = $HYPERRUN_DATA_DIR/tools/<tool_id>
    • 도구를 처음 실행할 때 lazy 생성된다.
    • pip/python처럼 한 툴에 속한 커맨드는 같은 tool_id라 tools/python을 공유한다.

    도구가 자기만의 HOME 환경변수를 쓰면, 툴 env 파일에서 매핑한다.

    # $HYPERRUN_DATA_DIR/env/tools/<tool>.env
FOO_HOME=${HYPERRUN_TOOL_HOME}
AWS_CONFIG_FILE=${HYPERRUN_TOOL_HOME}/config

    ${HYPERRUN_TOOL_HOME}는 툴 env 파일에서만 쓸 수 있다(툴 진입 후 로딩되기 때문). global.env/프로파일 env에 쓰면 그 시점엔 값이 없어 에러난다.

    트러블슈팅

    hrun doctor
hrun which <command>
hrun env <command>
HYPERRUN_TRACE=1 hrun <command>   # 선택된 네트워크/러너를 stderr로
