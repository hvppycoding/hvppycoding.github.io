    Verilog 난독화 코드 작성

    2025-07-24

    너는 pyverilog의 전문가야. 나를 도와줘. 나는 제품 관련 verilog 파일을 외부에 보내야해. 그런데 모듈명/인스턴스명/input 포트명, output 포트명, inout 포트명, net 명 등에 제품 정보가 들어가는걸 원치 않아. 그래서 변경하고자 해. module은 등장 순서대로 MODULE01, MODULE02 이런 식으로 네이밍 하고 input/output/inout 포트명도 in0, in1 이런 식으로 모두 바꾸는 코드를 작성해줘.

    좋습니다. Verilog 파일에서 민감한 정보를 제거하고 난독화된 형태로 바꾸기 위해서는 다음과 같은 작업이 필요합니다:

    1. module 이름을 등장 순서대로 MODULE01, MODULE02, … 식으로 변경

    2. 각 모듈의 포트 이름 (input/output/inout) 을 in0, out0, io0 등으로 변경

    3. 내부 net 이름 (wire, reg 등) 도 모두 net0, net1, … 식으로 변경

    4. 인스턴스 이름도 inst0, inst1, … 식으로 변경

    이를 수행하는 pyverilog 기반 스크립트를 아래에 작성해 드리겠습니다. Pyverilog의 AST를 활용하여 구문을 파싱하고 이름을 재매핑합니다.

    from pyverilog.vparser.parser import parse
from pyverilog.ast_code_generator.codegen import ASTCodeGenerator
from collections import defaultdict
import os

class VerilogAnonymizer:
    def __init__(self):
        self.module_count = 0
        self.port_count = 0
        self.net_count = 0
        self.instance_count = 0

        self.module_map = {}
        self.port_map = {}
        self.net_map = {}
        self.inst_map = {}

    def get_new_module_name(self):
        self.module_count += 1
        return f"MODULE{self.module_count:02d}"

    def get_new_port_name(self, direction):
        name = f"{direction}{self.port_count}"
        self.port_count += 1
        return name

    def get_new_net_name(self):
        name = f"net{self.net_count}"
        self.net_count += 1
        return name

    def get_new_instance_name(self):
        name = f"inst{self.instance_count}"
        self.instance_count += 1
        return name

    def anonymize(self, filename):
        ast, _ = parse([filename])
        description = ast.description

        for module in description.definitions:
            if module.name not in self.module_map:
                self.module_map[module.name] = self.get_new_module_name()
            module.name = self.module_map[module.name]

            for port in module.portlist:
                if port.name not in self.port_map:
                    if hasattr(port, 'direction'):
                        direction = port.direction
                    else:
                        direction = 'in'  # fallback
                    self.port_map[port.name] = self.get_new_port_name(direction[:2])
                    port.name = self.port_map[port.name]

            for item in module.items:
                if hasattr(item, 'name') and isinstance(item.name, str):
                    if hasattr(item, 'portlist'):
                        # Instance
                        if item.name not in self.inst_map:
                            self.inst_map[item.name] = self.get_new_instance_name()
                        item.name = self.inst_map[item.name]
                    elif hasattr(item, 'width'):
                        # Net
                        if item.name not in self.net_map:
                            self.net_map[item.name] = self.get_new_net_name()
                        item.name = self.net_map[item.name]

        codegen = ASTCodeGenerator()
        anonymized_code = codegen.visit(ast)
        return anonymized_code

# 사용 예시
if __name__ == "__main__":
    filename = "input.v"  # 원본 Verilog 파일
    anonymizer = VerilogAnonymizer()
    result = anonymizer.anonymize(filename)

    with open("anonymized.v", "w") as f:
        f.write(result)

    주의사항

    1. 이 코드는 간단한 구조의 Verilog 파일을 기준으로 합니다. 복잡한 generate 블록, 매크로, parameterized module 등은 처리에 추가 작업이 필요합니다.

    2. pyverilog는 일부 Verilog-2001 이후 문법에 대한 처리가 미흡할 수 있습니다. 컴파일이 안 되면 iverilog로 사전 확인 필요합니다.

    3. identifier 충돌 방지를 위해 기존 이름을 모두 맵핑 테이블로 따로 관리합니다.

    필요하시면, 해당 스크립트를 확장하여:

    • parameter, localparam 난독화

    • define 이름 변경

    • 파일 내부 주석 제거
      도 추가 가능합니다.

    아니면 이런 일을 하는 사용이 툴이 있어?

    예, 이런 작업을 자동으로 수행해주는 도구(툴)가 있긴 하지만, 완전히 안전하게 제품명을 난독화하면서도 Verilog 구조를 유지하는 범용적 툴은 사실상 없습니다. 하지만 유사하거나 일부 기능을 제공하는 도구들은 존재합니다:

    ✅ 1. Verible (by Google)

    • https://github.com/chipsalliance/verible

    • 용도 : 포맷터, 파서, 구조 분석기.

    • 장점 : SystemVerilog을 파싱하고 분석 가능

    • 단점 : 이름 난독화 기능은 직접 스크립트로 만들어야 함

    👉 즉, Verible로 코드를 파싱해서 symbol table 만들고, 그 위에 custom obfuscator 스크립트 를 짜는 방식

    ✅ 2. Surelog + UHDM

    • https://github.com/chipsalliance/Surelog

    • 용도 : SV 전체 파서 + UHDM(중간 표현) 생성

    • 장점 : 매우 강력한 구조 분석 가능 (RTL compiler 수준)

    • 단점 : 설정이 복잡하고, 난독화는 기본 지원하지 않음

    • 하지만 UHDM 기반으로 symbol rename은 구현 가능

    ✅ 3. Proprietary Commercial Tools (유료 도구들)

    • 일부 FPGA/ASIC 회사에서는 내부 obfuscation tool을 쓰기도 함

    • 예: Synopsys Identify , Cadence Stratus 등은 synthesis 도중 일부 renaming 기능 포함

    • 하지만 이건 IP 보호 목적이 아니라 컴파일 최적화 목적임

    ✅ 4. Obfuscation Scripts (Custom)

    • 현실적으로 대부분의 기업은 pyverilog, verilog-parser, ANTLR4 등으로 직접 custom tool을 짭니다

    • 특히:

      • 모듈/인스턴스/포트 이름 mapping

      • wire/reg rename

      • 주석 제거, define 제거

      • synthesis 안되는 이름 피하기

    결론:

    정리하면, 네 요구사항(제품명 노출 방지용 난독화)을 자동으로 완벽하게 처리하는 공개 툴은 없음. Verible/Surelog 같은 툴로 파싱하고, 이름 바꾸는 스크립트를 커스터마이징하는 게 현실적인 해결책입니다.

    필요하시다면 Verible이나 Surelog 기반으로 만드는 방식으로도 도와드릴 수 있습니다.
    예: Verible로 symbol 목록 추출 → rename map 생성 → 자동 대체 스크립트.

    이 방향으로 더 해볼까요?

    VerilogAnonymizer 수정해줘. 포트 방향이 portlist가 아니라 내부에 선언되어 있을 수도 있어

    맞습니다. Verilog에서는 포트 방향이 module 선언부가 아니라 내부 input, output, inout 선언 블록에만 나오는 경우가 많습니다. 예:

    module foo(a, b, c);
  input a, b;
  output c;
endmodule

    이걸 고려하려면 VerilogAnonymizer를 수정해서:

    1. 포트 방향을 내부 선언문에서 찾아야 하고,

    2. 해당 이름에 맞춰 direction을 결정한 뒤

    3. 포트 이름과 내부 포트 선언을 같이 바꿔야 합니다.

    아래는 그런 케이스를 포함해 module 포트 direction을 추적 하고 난독화하는 수정된 코드입니다:

    from pyverilog.vparser.parser import parse
from pyverilog.ast_code_generator.codegen import ASTCodeGenerator
from pyverilog.vparser.ast import Input, Output, Inout, Port, Portlist, Identifier
import os

class VerilogAnonymizer:
    def __init__(self):
        self.module_count = 0
        self.port_count = 0
        self.net_count = 0
        self.instance_count = 0

        self.module_map = {}
        self.port_map = {}
        self.net_map = {}
        self.inst_map = {}

    def get_new_module_name(self):
        self.module_count += 1
        return f"MODULE{self.module_count:02d}"

    def get_new_port_name(self, direction):
        name = f"{direction}{self.port_count}"
        self.port_count += 1
        return name

    def get_new_net_name(self):
        name = f"net{self.net_count}"
        self.net_count += 1
        return name

    def get_new_instance_name(self):
        name = f"inst{self.instance_count}"
        self.instance_count += 1
        return name

    def collect_port_directions(self, items):
        port_dir_map = {}
        for item in items:
            if isinstance(item, (Input, Output, Inout)):
                direction = 'in' if isinstance(item, Input) else 'out' if isinstance(item, Output) else 'io'
                for name in item.names:
                    port_dir_map[name.name] = direction
        return port_dir_map

    def anonymize(self, filename):
        ast, _ = parse([filename])
        description = ast.description

        for module in description.definitions:
            # 모듈 이름 변경
            orig_module_name = module.name
            if orig_module_name not in self.module_map:
                self.module_map[orig_module_name] = self.get_new_module_name()
            module.name = self.module_map[orig_module_name]

            # 포트 방향 수집
            port_directions = self.collect_port_directions(module.items)

            # 포트 이름 변경
            for port in module.portlist.ports:
                if isinstance(port, Port) and port.name:
                    orig_port_name = port.name
                    direction = port_directions.get(orig_port_name, 'in')  # default 'in'
                    if orig_port_name not in self.port_map:
                        self.port_map[orig_port_name] = self.get_new_port_name(direction)
                    port.name = self.port_map[orig_port_name]

                    # Port 인자 Identifier 도 바꿔야 함
                    if port.first and isinstance(port.first, Identifier):
                        port.first.name = self.port_map[orig_port_name]

            # 내부 선언 및 인스턴스 이름, net 이름 등 처리
            for item in module.items:
                # 포트 선언부 이름 변경
                if isinstance(item, (Input, Output, Inout)):
                    for name in item.names:
                        if name.name in self.port_map:
                            name.name = self.port_map[name.name]

                # net 이름 (wire, reg 등)
                if hasattr(item, 'name') and item.name:
                    if item.name not in self.net_map:
                        self.net_map[item.name] = self.get_new_net_name()
                    item.name = self.net_map[item.name]

                # 인스턴스 이름
                if hasattr(item, 'instances'):
                    for inst in item.instances:
                        if inst.name not in self.inst_map:
                            self.inst_map[inst.name] = self.get_new_instance_name()
                        inst.name = self.inst_map[inst.name]

                        # 포트 연결 이름 변경
                        for conn in inst.portlist:
                            if isinstance(conn.argname, Identifier):
                                old = conn.argname.name
                                if old in self.port_map:
                                    conn.argname.name = self.port_map[old]
                                elif old in self.net_map:
                                    conn.argname.name = self.net_map[old]

        # 결과 출력
        codegen = ASTCodeGenerator()
        return codegen.visit(ast)

# 사용 예시
if __name__ == "__main__":
    input_file = "input.v"
    output_file = "anonymized.v"

    anonymizer = VerilogAnonymizer()
    anonymized_code = anonymizer.anonymize(input_file)

    with open(output_file, "w") as f:
        f.write(anonymized_code)

    변경된 점 요약:

    • collect_port_directions 함수를 통해 포트 방향 추적

    • 포트 방향 기반으로 이름 결정 (in0, out1, io2 등)

    • 내부 선언과 포트 이름을 함께 매핑

    • 인스턴스 포트 연결된 이름까지 수정

    이제 포트 방향이 portlist가 아닌 내부 선언에 있어도 제대로 처리됩니다.

    원하시면 assign, always, generate, parameter까지 확장도 도와드릴 수 있습니다. 필요하신가요?

    Portlist object is not iterable

    좋은 지적입니다. 에러 메시지 "Portlist object is not iterable"는 이 부분에서 발생했을 가능성이 큽니다:

    for port in module.portlist:

    Portlist는 리스트가 아니라 객체이며, 내부에 있는 포트들은 portlist.ports를 통해 접근해야 합니다.

    🔧 수정 방법

    # 잘못된 코드
for port in module.portlist:

# 수정된 코드
for port in module.portlist.ports:

    ✅ 전체적으로 다시 확인된 수정 코드

    아래는 해당 문제를 포함해 수정된 전체 함수 일부입니다:

    # 포트 이름 변경
if module.portlist and module.portlist.ports:
    for port in module.portlist.ports:
        if isinstance(port, Port) and port.name:
            orig_port_name = port.name
            direction = port_directions.get(orig_port_name, 'in')  # default 'in'
            if orig_port_name not in self.port_map:
                self.port_map[orig_port_name] = self.get_new_port_name(direction)
            port.name = self.port_map[orig_port_name]

            # Port 인자 Identifier 도 바꿔야 함
            if port.first and isinstance(port.first, Identifier):
                port.first.name = self.port_map[orig_port_name]

    💬 팁

    • module.portlist → Portlist 객체

    • Portlist.ports → 포트들의 리스트 ([Port, Port, ...])

    • Port.first, Port.second 등은 포트가 연결된 구체적인 signal 이름

    필요하시면 pyverilog의 AST 구조를 탐색하는 ast.show() 도 같이 넣어드릴 수 있습니다. 계속 진행할까요?

    그리고 모듈이 바뀌었으면 그걸 참조하는 instance의 모듈명도 바뀌어야 해

    정확합니다.
    모듈 이름을 바꾸면 그 모듈을 인스턴스화한 상위 모듈 내부의module name 필드도 같이 바꿔줘야 합니다.
    안 그러면 MODULE01 u0(); 처럼 정의되지 않은 모듈명을 인스턴스로 쓰는 구조가 되어버려 RTL이 깨집니다.

    🔧 해결 전략

    1. 상위 모듈 내부에서 InstanceList에 접근

    2. InstanceList.module 필드가 원래 모듈 이름 임 → 이것도 self.module_map을 참조해서 수정

    ✅ 수정 코드 부분 예시 (anonymize() 함수 내부)

    from pyverilog.vparser.ast import InstanceList

# 내부 선언 및 인스턴스 이름, net 이름 등 처리
for item in module.items:
    # 포트 선언부 이름 변경
    if isinstance(item, (Input, Output, Inout)):
        for name in item.names:
            if name.name in self.port_map:
                name.name = self.port_map[name.name]

    # net 이름 (wire, reg 등)
    if hasattr(item, 'name') and isinstance(item.name, str):
        if item.name not in self.net_map:
            self.net_map[item.name] = self.get_new_net_name()
        item.name = self.net_map[item.name]

    # 인스턴스 리스트 처리
    if isinstance(item, InstanceList):
        # 여기에서 instance.module 은 문자열
        if item.module in self.module_map:
            item.module = self.module_map[item.module]

        for inst in item.instances:
            if inst.name not in self.inst_map:
                self.inst_map[inst.name] = self.get_new_instance_name()
            inst.name = self.inst_map[inst.name]

            # 포트 연결 이름 변경
            for conn in inst.portlist:
                if isinstance(conn.argname, Identifier):
                    old = conn.argname.name
                    if old in self.port_map:
                        conn.argname.name = self.port_map[old]
                    elif old in self.net_map:
                        conn.argname.name = self.net_map[old]

    📌 요점

    • InstanceList.module: 문자열로 된 인스턴스 대상 모듈명

    • 그 모듈명이 self.module_map에 있으면 치환해야 함

    • Instance.name, Instance.portlist도 그대로 처리

    전체 완성 코드 작성해줘.

    알겠습니다. 아래는 다음 요구사항을 모두 반영한 완성된 Verilog 난독화 스크립트 (VerilogAnonymizer) 입니다:

    ✅ 포함된 기능

    1. 모듈 이름 변경 → MODULE01, MODULE02, …

    2. 포트 이름 변경 (방향에 따라) → in0, out1, io2, …

    3. 내부 포트 선언도 이름 변경

    4. net 이름 (wire/reg 등) 변경 → net0, net1, …

    5. 인스턴스 이름 변경 → inst0, …

    6. 인스턴스화된 모듈명도 변경 (중요)

    🧠 의존 라이브러리

    • pyverilog
    pip install pyverilog

    📜 전체 코드

from pyverilog.ast_code_generator.codegen import ASTCodeGenerator
from pyverilog.vparser.ast import (

    InstanceList, Instance, Decl, Wire, Reg

    def anonymize(self, filename):
        ast, _ = parse([filename])
        description = ast.description

        # 1차: 모든 모듈 이름 미리 변경
        for module in description.definitions:
            if module.name not in self.module_map:
                self.module_map[module.name] = self.get_new_module_name()

        for module in description.definitions:
            orig_module_name = module.name
            module.name = self.module_map[orig_module_name]

            # 포트 방향 수집
            port_directions = self.collect_port_directions(module.items)

            # 포트 이름 변경
            if module.portlist and module.portlist.ports:
                for port in module.portlist.ports:
                    if isinstance(port, Port) and port.name:
                        orig_port_name = port.name
                        direction = port_directions.get(orig_port_name, 'in')  # 기본값 in
                        if orig_port_name not in self.port_map:
                            self.port_map[orig_port_name] = self.get_new_port_name(direction)
                        port.name = self.port_map[orig_port_name]

                        # 연결된 식별자도 변경
                        if port.first and isinstance(port.first, Identifier):
                            port.first.name = self.port_map[orig_port_name]

            # 내부 선언 처리
            for item in module.items:
                # input/output/inout 포트 이름 변경
                if isinstance(item, (Input, Output, Inout)):
                    for name in item.names:
                        if name.name in self.port_map:
                            name.name = self.port_map[name.name]

                # wire, reg 등 net 이름 변경
                if isinstance(item, Decl):
                    for decl in item.list:
                        if isinstance(decl, (Wire, Reg)):
                            if decl.name not in self.net_map:
                                self.net_map[decl.name] = self.get_new_net_name()
                            decl.name = self.net_map[decl.name]

                # 인스턴스 모듈명 및 인스턴스 이름 변경
                if isinstance(item, InstanceList):
                    if item.module in self.module_map:
                        item.module = self.module_map[item.module]
                    for inst in item.instances:
                        if inst.name not in self.inst_map:
                            self.inst_map[inst.name] = self.get_new_instance_name()
                        inst.name = self.inst_map[inst.name]

                        # 포트 연결 이름 변경
                        for conn in inst.portlist:
                            if isinstance(conn.argname, Identifier):
                                old = conn.argname.name
                                if old in self.port_map:
                                    conn.argname.name = self.port_map[old]
                                elif old in self.net_map:
                                    conn.argname.name = self.net_map[old]

        # 최종 코드 생성
        codegen = ASTCodeGenerator()
        anonymized_code = codegen.visit(ast)
        return anonymized_code

    output_file = "anonymized.v"    # 결과 저장

    원하시나요?

    Port object has no attribute first

    맞습니다. Port 객체는 모든 경우에 .first 속성을 가지지 않습니다. pyverilog에서 Port 객체는 두 가지 방식 으로 정의될 수 있고, .first, .second는 그중 일부에서만 사용됩니다.

    🔍 문제 원인 정리

    if port.first and isinstance(port.first, Identifier):
    port.first.name = self.port_map[orig_port_name]

    이 코드는 .first가 없는 Port 객체에 접근하면서 에러가 발생하는 것입니다.

    🛠 해결 방법

    Port 객체는 다음 두 형태 중 하나로 구성됩니다:

    1. Simple Identifier only (no direction)
      예: Port('a') → port.name == 'a', port.first == None

    2. Port with Identifier and declaration
      예: Port('a', first=Identifier('a'))

    따라서 .first가 있는지 hasattr()으로 체크하거나, 보다 안전하게 try/except 없이 처리해야 합니다.

    ✅ 안전한 수정 코드

    if hasattr(port, "first") and isinstance(port.first, Identifier):
    old = port.first.name
    if old in self.port_map:
        port.first.name = self.port_map[old]

    또는 더 확실하게 하려면, .first 있는 경우만 수정하도록 조건 분기:

    # 포트 이름 변경
if module.portlist and module.portlist.ports:
    for port in module.portlist.ports:
        if isinstance(port, Port) and port.name:
            orig_port_name = port.name
            direction = port_directions.get(orig_port_name, 'in')
            if orig_port_name not in self.port_map:
                self.port_map[orig_port_name] = self.get_new_port_name(direction)
            port.name = self.port_map[orig_port_name]

            # first 필드가 Identifier일 때만 수정
            if hasattr(port, "first") and isinstance(port.first, Identifier):
                port.first.name = self.port_map[orig_port_name]

    📌 요약

    • Port.first는 항상 존재하는 속성이 아님

    • hasattr() 또는 타입 확인을 통해 존재 여부 확인 필요

    • Verilog 스타일에 따라 포트 정의 방식이 다름

    이제 이 문제는 해결됐습니다.
    전체 코드를 다시 정리된 버전으로 드릴까요?

    본문에 input A; input B 이런게 그대로 남아 있어.

    좋습니다. 정확히 보셨습니다.

    🔍 현재 문제 요약

    input A; input B; 같은 선언문은 여전히 원래 이름 A, B로 남아 있으며 난독화되지 않았다는 뜻입니다.

    이유는 다음과 같습니다:

    • 우리는 Input, Output, Inout 노드를 순회하면서 .names 리스트 안의 name.name 값만 수정했는데,

    • 실제로 이건 Decl 블록 안에 들어있는 경우가 많고,

    • 각 포트 선언은 Input(name=A), Input(name=B) 등으로 따로 존재합니다.

    🛠 해결 방법

    아래 두 가지 조건을 추가해야 합니다:

    1. Decl 블록 내부의 Input, Output, Inout 각각의 이름도 확인하고,

    2. 그 이름이 기존 포트이거나 net이라면 port_map 또는 net_map으로 바꿔줘야 함.

    ✅ 수정 코드: 포트 선언부 제대로 바꾸기

    if isinstance(item, Decl):
    for decl in item.list:
        # 포트 선언
        if isinstance(decl, (Input, Output, Inout)):
            for name in decl.names:
                if name.name in self.port_map:
                    name.name = self.port_map[name.name]

        # net 선언 (wire, reg 등)
        elif isinstance(decl, (Wire, Reg)):
            if decl.name not in self.net_map:
                self.net_map[decl.name] = self.get_new_net_name()
            decl.name = self.net_map[decl.name]

  output b;
endmodule

    🔄 출력 기대값

    module MODULE01(in0, out0);

    📌 주의할 점

    • Input, Output의 .names는 리스트이며, 각각 Identifier 객체입니다. 그 내부 .name을 수정해야 합니다.

    • Reg, Wire는 .name만 수정하면 됩니다.

    필요하시면 전체 코드 버전을 이 수정 사항을 반영해서 다시 정리해드릴 수 있습니다. 요청하시면 바로 드리겠습니다.

    전체 코드 작성해줘

    알겠습니다. 아래는 지금까지 말씀하신 모든 사항을 반영한 완성된 Verilog 난독화 스크립트 입니다.

    ✅ 주요 기능 요약:

    • 모든 module 이름 → MODULE01, MODULE02, …

    • 모든 포트 이름 (input, output, inout) → 방향별 in0, out1, io2, …

    • 포트 선언 (input a; input b;) → 새 이름으로 변경

    • 내부 wire, reg → net0, net1, …

    • 인스턴스 이름 → inst0, inst1, …

    • 인스턴스 대상 모듈명도 함께 변경

    📜 전체 코드

    from pyverilog.vparser.parser import parse
from pyverilog.ast_code_generator.codegen import ASTCodeGenerator
from pyverilog.vparser.ast import (
    Input, Output, Inout, Port, Portlist, Identifier,
    InstanceList, Instance, Decl, Wire, Reg
)

class VerilogAnonymizer:
    def __init__(self):
        self.module_count = 0
        self.port_count = 0
        self.net_count = 0
        self.instance_count = 0

        self.module_map = {}
        self.port_map = {}
        self.net_map = {}
        self.inst_map = {}

    def get_new_module_name(self):
        self.module_count += 1
        return f"MODULE{self.module_count:02d}"

    def get_new_port_name(self, direction):
        name = f"{direction}{self.port_count}"
        self.port_count += 1
        return name

    def get_new_net_name(self):
        name = f"net{self.net_count}"
        self.net_count += 1
        return name

    def get_new_instance_name(self):
        name = f"inst{self.instance_count}"
        self.instance_count += 1
        return name

    def collect_port_directions(self, items):
        port_dir_map = {}
        for item in items:
            if isinstance(item, (Input, Output, Inout)):
                direction = 'in' if isinstance(item, Input) else 'out' if isinstance(item, Output) else 'io'
                for name in item.names:
                    port_dir_map[name.name] = direction
        return port_dir_map

    def anonymize(self, filename):
        ast, _ = parse([filename])
        description = ast.description

        # 모든 모듈 이름 미리 mapping
        for module in description.definitions:
            if module.name not in self.module_map:
                self.module_map[module.name] = self.get_new_module_name()

        for module in description.definitions:
            orig_module_name = module.name
            module.name = self.module_map[orig_module_name]

            # 포트 방향 수집
            port_directions = self.collect_port_directions(module.items)

            # 포트 이름 변경
            if module.portlist and module.portlist.ports:
                for port in module.portlist.ports:
                    if isinstance(port, Port) and port.name:
                        orig_port_name = port.name
                        direction = port_directions.get(orig_port_name, 'in')  # default 'in'
                        if orig_port_name not in self.port_map:
                            self.port_map[orig_port_name] = self.get_new_port_name(direction)
                        port.name = self.port_map[orig_port_name]

                        if hasattr(port, "first") and isinstance(port.first, Identifier):
                            port.first.name = self.port_map[orig_port_name]

            # 내부 선언 및 인스턴스 처리
            for item in module.items:
                if isinstance(item, Decl):
                    for decl in item.list:
                        # 포트 선언 변경
                        if isinstance(decl, (Input, Output, Inout)):
                            for name in decl.names:
                                if name.name in self.port_map:
                                    name.name = self.port_map[name.name]
                        # wire, reg 등 net 이름 변경
                        elif isinstance(decl, (Wire, Reg)):
                            if decl.name not in self.net_map:
                                self.net_map[decl.name] = self.get_new_net_name()
                            decl.name = self.net_map[decl.name]

                elif isinstance(item, InstanceList):
                    # 인스턴스 대상 모듈 이름 변경
                    if item.module in self.module_map:
                        item.module = self.module_map[item.module]

                    for inst in item.instances:
                        if inst.name not in self.inst_map:
                            self.inst_map[inst.name] = self.get_new_instance_name()
                        inst.name = self.inst_map[inst.name]

                        for conn in inst.portlist:
                            if isinstance(conn.argname, Identifier):
                                old = conn.argname.name
                                if old in self.port_map:
                                    conn.argname.name = self.port_map[old]
                                elif old in self.net_map:
                                    conn.argname.name = self.net_map[old]

        # 최종 코드 출력
        codegen = ASTCodeGenerator()
        return codegen.visit(ast)
