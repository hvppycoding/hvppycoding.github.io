    Pyverilog 인스턴스 CSV 생성

    2025-08-08

    pyverilog 이용해서 top module 바로 아래에 위치한 모든 인스턴스에 대해 모듈명, 인스턴스명을 csv로 만들고 싶어.

    좋아요! pyverilog 로 “top 모듈 바로 아래에 있는 모든 인스턴스”의 모듈명, 인스턴스명 을 CSV로 뽑는 가장 간단한 스크립트를 드릴게요.
    (직계 하위만 대상으로, generate 안쪽이나 더 깊은 계층은 탐색하지 않습니다.)

    사용법 요약

    python dump_top_instances.py -t TOP_MODULE \
  -o out.csv \
  -I include/ -I rtl/include \
  -D SYNTH=1 -D FOO=BAR \
  rtl/top.sv rtl/a.v rtl/b.v

    스크립트

    #!/usr/bin/env python3
# dump_top_instances.py
import argparse, csv, sys
from pyverilog.vparser.parser import parse
from pyverilog.vparser.ast import ModuleDef, InstanceList

def find_top_module(ast, top_name):
    # ast.description.definitions 안에서 모듈 정의 찾기
    for d in getattr(ast.description, 'definitions', []):
        if isinstance(d, ModuleDef) and d.name == top_name:
            return d
    return None

def collect_direct_instances(top_def: ModuleDef):
    """
    top 모듈의 직계 하위 인스턴스만 수집
    (Generate 블록 내부나 하위 계층은 보지 않음)
    반환: [(module_name, instance_name), ...]
    """
    rows = []
    for item in getattr(top_def, 'items', []) or []:
        if isinstance(item, InstanceList):
            modname = item.module  # 인스턴스의 모듈명 (str)
            for inst in item.instances:
                rows.append((modname, inst.name))
    return rows

def main():
    p = argparse.ArgumentParser(description="Dump direct child instances of a top module to CSV")
    p.add_argument("files", nargs="+", help="Verilog/SystemVerilog source files")
    p.add_argument("-t", "--top", required=True, help="Top module name")
    p.add_argument("-o", "--out", default="instances.csv", help="Output CSV path (default: instances.csv)")
    p.add_argument("-I", "--incdir", action="append", default=[], help="Include directories (repeatable)")
    p.add_argument("-D", "--define", action="append", default=[], help="Preprocessor defines (e.g., FOO=1). Repeatable")
    args = p.parse_args()

    # pyverilog 전처리 옵션 구성
    incs = args.incdir or []
    defs = args.define or []

    ast, _ = parse(
        args.files,
        preprocess_include=incs,
        preprocess_define=defs
    )

    top_def = find_top_module(ast, args.top)
    if top_def is None:
        sys.stderr.write(f"[ERROR] Top module '{args.top}' not found.\n")
        sys.exit(1)

    rows = collect_direct_instances(top_def)

    with open(args.out, "w", newline="") as f:
        w = csv.writer(f)
        w.writerow(["module", "instance"])
        for m, i in rows:
            w.writerow([m, i])

    print(f"Wrote {len(rows)} rows to {args.out}")

if __name__ == "__main__":
    main()

    체크 포인트

    • 정확히 “top 바로 아래”만 원하셔서 InstanceList만 훑습니다.
      (만약 generate 블록 안의 인스턴스도 포함하고 싶으면, GenerateStatement 등을 재귀적으로 내려가게 바꿔드릴 수 있어요.)

    • 전처리가 필요한 경우 -I, -D 옵션을 적절히 넣어주세요.

    • SystemVerilog(.sv)도 pyverilog 전처리/파서가 처리 가능한 한 읽힙니다(문법적으로 너무 최신 기능은 제한이 있을 수 있어요).

    원하시면 generate 내부까지 포함 하는 버전이나, CSV 컬럼 추가(파일/라인, 파라미터 값 등) 도 바로 확장해 드릴게요.
