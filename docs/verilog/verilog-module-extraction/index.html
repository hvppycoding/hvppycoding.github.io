    Verilog 모듈 추출 코드

    2025-08-22

    Developer: # 목적 - Verilog netlist가 주어졌을 때, 특정 모듈만 파일로 추출하는 Python 코드를 작성한다. # 지침 - 외부 설치 패키지 없이 구현할 것. - define 등의 preprocessor 지시문이 존재할 수 있으므로 이를 고려해 코드 작성. # 참고 및 범위 - 입력: Verilog netlist 파일과 추출하려는 모듈명이 주어진다. - Netlist 구조는 일반적인 Verilog 문법을 따른다. - define, ifdef, 주석 등 다양한 preprocessor 지시문 혹은 주석이 포함될 수 있다. - 출력은 지정한 모듈만을 포함하는 Verilog 파일이어야 한다. # 작업 체크리스트 1. 입력 파일 및 추출 대상 모듈명 파악 2. 주어진 netlist에서 대상 모듈 정의와 관련 preprocessor 블록 추출 3. 추출 결과가 대상 모듈만 포함하는지 확인 4. 지정한 파일로 출력 # 추가 지침 - 코드 작성 전, 위 체크리스트에 따라 계획을 간단히 작성하고 진행한다. - 각 주요 단계(파싱, 추출, 저장) 이후, 결과가 요구 사항을 만족하는지 1-2줄로 간단히 검증한다. - reasoning_effort는 medium으로 하여, 복잡한 처리엔 추가 설명을 덧붙일 수 있다.

    좋아요! 아래 순서로 진행할게요 — (요청하신 체크리스트/계획 → 코드 → 간단 검증 포인트).

    계획 (체크리스트 기준)

    1. 입력 파악

      • CLI 인자: 입력 Verilog 파일 경로, 추출할 모듈명, 출력 파일 경로(옵션), include 탐색 경로(옵션).

    2. 전처리/파싱

      • 주석 제거(//, /* */), 문자열 보존.

      • Verilog 전처리 지시문 처리: `` define/undef/ifdef/ifndef/elsif/else/endif/include (재귀적으로 포함).

      • 활성화된(조건을 통과한) 텍스트만 남긴 “전처리 완료 코드”를 생산.

    3. 추출

      • 전처리 완료 코드에서 대상 모듈module <name> ... endmodule 딱 1개 블록을 정규식으로 캡처.

      • 모듈 외부 최상위 레벨의 전처리 줄(예: timescale`,` `default_nettype`, define/undef)을 상단에 함께 포함 → 모듈이 매크로를 사용할 때도 독립적으로 사용 가능.

    4. 저장 & 검증

      • 산출물은 “최상위 전처리 줄들 + 대상 모듈 정의”만 포함.

      • 저장 전후 간단 검증: 모듈 개수=1, 다른 모듈 없음, 파일 생성 확인.

    Python 스크립트

    아래 코드는 외부 패키지 없이 동작합니다.

    #!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
extract_verilog_module.py
- 하나의 Verilog netlist에서 지정한 모듈만 추출하여 단일 파일로 저장
- 외부 패키지 없이 전처리 지시문(`define/ifdef/ifndef/elsif/else/endif/include`)을 간단 평가
- 주석 제거 지원(//, /* */), 문자열 리터럴 보존
- 최상위 레벨 전처리 줄(`timescale`, `default_nettype`, `define`, `undef`)은 결과 상단에 유지

사용법:
  python extract_verilog_module.py <input.v> <module_name> [-o out.v] [-I dir1 -I dir2 ...] [--verbose]

제약/가정:
- 매크로의 **치환(expansion)** 자체는 하지 않음. (조건부 컴파일만 평가)
- `include "file.v"` 형태를 기본으로 지원(상대경로는 입력 파일 기준/또는 -I 디렉토리 검색)
- 중첩 조건 처리/다중 파일 include 처리, 재귀 깊이 제한
"""

import argparse
import os
import re
import sys

# ---------------------------
# 유틸: 주석 제거 (문자열은 보존)
# ---------------------------
def strip_comments(text: str) -> str:
    res = []
    i = 0
    n = len(text)
    in_sl = False      # // ... \n
    in_ml = False      # /* ... */
    in_sq = False      # '...'
    in_dq = False      # "..."
    while i < n:
        ch = text[i]
        nxt = text[i+1] if i+1 < n else ''

        # 문자열 토글(escape 고려)
        if not in_sl and not in_ml:
            if ch == "'" and not in_dq:
                # 토글(이전이 escape인지 확인)
                backslashes = 0
                j = i - 1
                while j >= 0 and text[j] == '\\':
                    backslashes += 1
                    j -= 1
                if backslashes % 2 == 0:
                    in_sq = not in_sq
                res.append(ch)
                i += 1
                continue
            if ch == '"' and not in_sq:
                backslashes = 0
                j = i - 1
                while j >= 0 and text[j] == '\\':
                    backslashes += 1
                    j -= 1
                if backslashes % 2 == 0:
                    in_dq = not in_dq
                res.append(ch)
                i += 1
                continue

        # 주석 상태가 아닐 때만 주석 시작 인식
        if not in_sq and not in_dq:
            if not in_ml and not in_sl and ch == '/' and nxt == '/':
                in_sl = True
                i += 2
                continue
            if not in_ml and not in_sl and ch == '/' and nxt == '*':
                in_ml = True
                i += 2
                continue

        # 한줄 주석 종료
        if in_sl:
            if ch == '\n':
                in_sl = False
                res.append(ch)  # 개행은 유지
            i += 1
            continue

        # 블록 주석 종료
        if in_ml:
            if ch == '*' and nxt == '/':
                in_ml = False
                i += 2
            else:
                i += 1
            continue

        # 일반 문자
        res.append(ch)
        i += 1
    return ''.join(res)

# ---------------------------
# 전처리 (조건부 컴파일/인클루드)
# ---------------------------
PP_RE = re.compile(r'^\s*`(\w+)(?:\s+(.*))?$', re.ASCII)

def _parse_macro_name(arg: str) -> str:
    if not arg:
        return ''
    # 첫 토큰만 이름으로 간주
    return re.split(r'\s+', arg.strip(), maxsplit=1)[0]

def preprocess(text: str, base_dir: str, include_dirs=None, defines=None, verbose=False, _visited=None, depth=0, max_depth=32) -> str:
    """
    조건부 컴파일을 평가하여 활성 코드만 남긴다.
    - `define/undef`: 매크로 집합 갱신
    - `ifdef/ifndef/elsif/else/endif`: 조건 분기 활성/비활성
    - `include`: 파일을 읽어 재귀적으로 전처리 후 인라인
    - 그 외 지시문은 그대로 통과(단, 비활성 구간이면 무시)

    반환: 전처리 후 텍스트(주석 제거 후 적용)
    """
    if depth > max_depth:
        raise RuntimeError("Include/preprocess recursion too deep")

    if include_dirs is None:
        include_dirs = []
    if defines is None:
        defines = set()
    if _visited is None:
        _visited = set()

    lines = text.splitlines()
    out_lines = []

    # 조건 스택 프레임: { 'prev_active': bool, 'branch_taken': bool, 'this_active': bool }
    stack = []
    current_active = True

    def log(msg):
        if verbose:
            sys.stderr.write(msg + "\n")

    i = 0
    while i < len(lines):
        line = lines[i]
        m = PP_RE.match(line)
        if m:
            kw = m.group(1)
            arg = (m.group(2) or "").strip()

            if kw in ('ifdef', 'ifndef', 'elsif', 'else', 'endif'):
                if kw == 'ifdef':
                    name = _parse_macro_name(arg)
                    cond = (name in defines)
                    frame = {'prev_active': current_active, 'branch_taken': cond, 'this_active': cond}
                    current_active = frame['prev_active'] and frame['this_active']
                    stack.append(frame)
                elif kw == 'ifndef':
                    name = _parse_macro_name(arg)
                    cond = not (name in defines)
                    frame = {'prev_active': current_active, 'branch_taken': cond, 'this_active': cond}
                    current_active = frame['prev_active'] and frame['this_active']
                    stack.append(frame)
                elif kw == 'elsif':
                    if not stack:
                        raise RuntimeError("`elsif without matching `ifdef/ifndef")
                    name = _parse_macro_name(arg)
                    frame = stack[-1]
                    if frame['prev_active'] and (not frame['branch_taken']) and (name in defines):
                        frame['this_active'] = True
                        frame['branch_taken'] = True
                    else:
                        frame['this_active'] = False
                    current_active = frame['prev_active'] and frame['this_active']
                elif kw == 'else':
                    if not stack:
                        raise RuntimeError("`else without matching `ifdef/ifndef")
                    frame = stack[-1]
                    if frame['prev_active'] and (not frame['branch_taken']):
                        frame['this_active'] = True
                        frame['branch_taken'] = True
                    else:
                        frame['this_active'] = False
                    current_active = frame['prev_active'] and frame['this_active']
                elif kw == 'endif':
                    if not stack:
                        raise RuntimeError("`endif without matching `ifdef/ifndef")
                    frame = stack.pop()
                    current_active = frame['prev_active']
                # 조건 지시문 자체는 출력하지 않음(평가만)
                i += 1
                continue

            # define/undef/include 등은 활성 구간에서만 적용
            if current_active and kw == 'define':
                name = _parse_macro_name(arg)
                if name:
                    defines.add(name)
                # define 줄은 출력으로 보존(최상위 전처리라인 수집 단계에서 사용)
                out_lines.append(line)
                i += 1
                continue
            if current_active and kw == 'undef':
                name = _parse_macro_name(arg)
                if name and name in defines:
                    defines.remove(name)
                out_lines.append(line)
                i += 1
                continue
            if current_active and kw == 'include':
                # `include "path.v"` 혹은 <path>
                inc_arg = arg.strip()
                inc_path = None
                m1 = re.match(r'"([^"]+)"', inc_arg)
                m2 = re.match(r'<([^>]+)>', inc_arg)
                cand = None
                if m1:
                    cand = m1.group(1)
                elif m2:
                    cand = m2.group(1)
                if cand:
                    # 탐색: base_dir → -I dirs
                    search_dirs = [base_dir] + list(include_dirs)
                    for d in search_dirs:
                        p = os.path.abspath(os.path.join(d, cand))
                        if os.path.isfile(p):
                            inc_path = p
                            break
                if not inc_path:
                    raise FileNotFoundError(f"Cannot resolve include: {arg}")
                if inc_path in _visited:
                    log(f"[warn] include loop skipped: {inc_path}")
                    i += 1
                    continue
                _visited.add(inc_path)
                with open(inc_path, 'r', encoding='utf-8', errors='ignore') as f:
                    raw = f.read()
                raw = strip_comments(raw)
                inc_processed = preprocess(raw,
                                           base_dir=os.path.dirname(inc_path),
                                           include_dirs=include_dirs,
                                           defines=defines,
                                           verbose=verbose,
                                           _visited=_visited,
                                           depth=depth+1,
                                           max_depth=max_depth)
                out_lines.append(inc_processed)
                i += 1
                continue

            # 그 외의 backtick 지시문은 활성 구간이면 그대로 통과
            if current_active:
                out_lines.append(line)
            i += 1
            continue

        # 일반 라인: 활성 구간만 출력
        if current_active:
            out_lines.append(line)
        i += 1

    if stack:
        raise RuntimeError("Unclosed `ifdef/`ifndef block(s) detected.")
    return "\n".join(out_lines) + "\n"

# ---------------------------
# 최상위 전처리 줄 추출
# ---------------------------
TOP_PP_LINE = re.compile(r'^\s*`(timescale|default_nettype|define|undef)\b', re.ASCII)
MOD_START = re.compile(r'^\s*module\b', re.MULTILINE)
MOD_END   = re.compile(r'^\s*endmodule\b', re.MULTILINE)

def collect_top_level_preproc(text: str) -> str:
    """
    전처리 완료 코드에서 '모듈 바깥(최상위)'에 존재하는 전처리 줄만 수집
    """
    out = []
    in_module = 0
    for line in text.splitlines():
        if MOD_START.match(line):
            in_module += 1
        if in_module == 0 and TOP_PP_LINE.match(line):
            out.append(line)
        if MOD_END.match(line) and in_module > 0:
            in_module -= 1
    return "\n".join(out) + ("\n" if out else "")

# ---------------------------
# 모듈 본문 추출
# ---------------------------
def extract_module(text: str, module_name: str) -> str:
    # 모듈 블록 캡처: module <name> ... endmodule (non-greedy)
    # 모듈명 뒤에는 공백/괄호/파라미터 등이 올 수 있으므로 \b 이후 .*? 사용
    pattern = re.compile(rf'(?ms)^\s*module\s+{re.escape(module_name)}\b.*?^\s*endmodule\b')
    m = pattern.search(text)
    if not m:
        raise ValueError(f"Module '{module_name}' not found.")
    return m.group(0).strip() + "\n"

# ---------------------------
# 검증 함수
# ---------------------------
def sanity_check_output(final_text: str, module_name: str) -> None:
    # 모듈 개수=1
    mods = re.findall(r'(?m)^\s*module\b', final_text)
    if len(mods) != 1:
        raise AssertionError(f"Output contains {len(mods)} modules (expected 1).")
    # 대상 모듈명의 존재
    if not re.search(rf'(?m)^\s*module\s+{re.escape(module_name)}\b', final_text):
        raise AssertionError("Target module name not found in output.")

# ---------------------------
# 메인
# ---------------------------
def main():
    ap = argparse.ArgumentParser(description="Extract a single Verilog module (with top-level preprocessor lines).")
    ap.add_argument("input", help="Input Verilog netlist file")
    ap.add_argument("module", help="Target module name to extract")
    ap.add_argument("-o", "--output", help="Output Verilog file (default: <module>.v)")
    ap.add_argument("-I", "--include-dir", action="append", default=[], help="Additional include search directory (repeatable)")
    ap.add_argument("--verbose", action="store_true", help="Print stage-wise checks")
    args = ap.parse_args()

    in_path = os.path.abspath(args.input)
    if not os.path.isfile(in_path):
        print(f"[error] input not found: {in_path}", file=sys.stderr)
        sys.exit(1)
    base_dir = os.path.dirname(in_path)
    out_path = os.path.abspath(args.output if args.output else f"{args.module}.v")

    # 1) 입력 파악 OK
    if args.verbose:
        print(f"[check-1] input='{in_path}', target_module='{args.module}', out='{out_path}'")

    # 2) 전처리: 주석 제거 → 조건부/인클루드 평가
    with open(in_path, 'r', encoding='utf-8', errors='ignore') as f:
        raw = f.read()
    no_comments = strip_comments(raw)
    preprocessed = preprocess(no_comments, base_dir=base_dir, include_dirs=args.include_dir, verbose=args.verbose)

    if args.verbose:
        # 간단 검증: 전처리 결과가 비어있지 않고, 텍스트 내 backtick 지시문은 대부분 평가되어 줄어들었는지(대략적)
        line_cnt = len(preprocessed.splitlines())
        rem_ifdefs = len(re.findall(r'(?m)^\s*`ifn?def\b', preprocessed))
        print(f"[check-2] preprocessed lines={line_cnt}, remaining_ifdefs={rem_ifdefs} (should be 0)")

    # 3) 모듈 및 최상위 전처리 줄 추출
    top_pp = collect_top_level_preproc(preprocessed)
    body = extract_module(preprocessed, args.module)
    final_text = ""
    if top_pp.strip():
        final_text += top_pp
        if not top_pp.endswith("\n"):
            final_text += "\n"
    final_text += body

    # 간단 검증: 결과가 대상 모듈만 포함하는지
    try:
        sanity_check_output(final_text, args.module)
        if args.verbose:
            print("[check-3] output contains exactly one module (the target).")
    except AssertionError as e:
        print(f"[error] sanity check failed: {e}", file=sys.stderr)
        sys.exit(2)

    # 4) 저장
    with open(out_path, 'w', encoding='utf-8') as f:
        f.write(final_text)

    if args.verbose:
        size = os.path.getsize(out_path)
        print(f"[check-4] wrote '{out_path}' ({size} bytes)")

if __name__ == "__main__":
    main()

    # 기본 사용 (out 파일은 <module>.v 로 저장)
python extract_verilog_module.py chip_top_netlist.v my_block

# 출력 파일 지정
python extract_verilog_module.py chip_top_netlist.v my_block -o my_block_only.v

# include 디렉토리 추가(+여러 번 지정 가능)

    단계별 간단 검증 (코드에 내장된 출력, --verbose 사용 시)

    • [check-1] 입력 경로/모듈명/출력 경로 확인 → 인자 파싱 정상 여부.

    • [check-2] 전처리 결과 라인수와 남은 ` ifdef/ifndef` 카운트 표시 → 조건부가 평가되어 비활성 분기가 제거되었는지 대략 확인.

    • [check-3] 결과물 내 모듈 개수=1, 대상 모듈 존재 확인 → “지정한 모듈만 포함” 조건 확인.

    • [check-4] 출력 파일 바이트 수 표시 → 파일 생성/저장 확인.

    구현 메모/제약

    • 매크로 치환(text substitution)은 하지 않고 , 조건부 활성 여부만 평가합니다. 그래서 모듈이 ` WIDTH 같은 매크로를 사용한다면, 최상위 레벨의define/undef/timescale/`default_nettype 줄들을 함께 보존하여 독립 사용을 돕습니다.

    • include는 입력 파일 기준 상대경로 및 -I 디렉토리에서 탐색합니다. 순환 include는 1회 경고 후 무시합니다.

    • 전처리 블록(ifdef 등) 그 자체를 보존하지는 않지만 , 활성 분기만 남기므로 “컴파일 관점의 결과물”을 얻는 데 초점을 맞췄습니다.

    • Netlist에서 module/endmodule 키워드를 라인 단위로 인식합니다(주석은 제거되어 혼동 최소화).

    필요하시면 preprocess 단계에서 전처리 블록을 그대로 감싸서 보존하는 모드(예: 모듈을 감싸는 ifdef/endif를 재구성)도 추가해드릴게요.

    전처리를 안하고 그냥 하도록 해줘. 최대한 원본을 유지하고 싶어. 모듈만 딱 떼와서 다시 붙이면 쓸 수 있게.

    좋아요—요청대로 전처리 없이, 원본을 최대한 보존 해서 module <name> ... endmodule 블록만 정밀 추출하도록 바꿉니다. (주석/문자열은 그대로 유지, 조건부 컴파일도 평가하지 않음)

    계획(업데이트)

    1. 입력 파악 : 파일 경로, 모듈명, 출력 경로(옵션).

    2. 파싱(전처리 없음) :

      • 원본 텍스트에서 주석/문자열은 유지 하되, 토큰 인식 시에만 주석/문자열 내부의 module/endmodule를 무시하는 스캐너 로 경계를 찾음.

      • module 뒤의 모듈명 토큰(일반/escape 식별자 \...)을 정확히 읽어 타겟과 일치 시 시작점 고정.

      • 이후 동일 파일 내 첫endmodule(필요 시 중첩 깊이 카운팅)까지의 원문 구간 그대로 슬라이스.

    3. 추출 : 찾은 바이트 범위를 그대로 출력(선택 플래그 없이 기본은 모듈 본문만).

    4. 저장 & 검증: 결과물에 module 1개, endmodule 1개가 존재하는지 확인 후 저장.

    간단 검증은 각 단계에서 1~2줄 메시지로 출력하도록 --verbose 옵션 제공.

    Python 스크립트 (전처리/치환 없음, 원본 유지)

    #!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
extract_verilog_module_raw.py
- 전처리/치환 없이, 원본을 그대로 유지한 채 특정 모듈 블록만 정확히 잘라냄.
- 주석/문자열은 파일에 남김. 다만 '경계 탐지' 시에는 주석/문자열 내부 키워드는 무시.
- 모듈명: 일반 식별자([A-Za-z_][A-Za-z0-9_$]*) 또는 escape 식별자(\...<space>) 모두 지원.

사용:
  python extract_verilog_module_raw.py <input.v> <module_name> [-o out.v] [--verbose]

주의:
- 매크로/조건부(`ifdef` 등)는 **평가나 이동을 하지 않음**. 모듈 블록 안에 있는 것은 그대로 따라옴.
- 파일 상단의 `timescale`/`define` 등을 자동 포함하지 않음(요청이 '모듈만'이라 기본 보수적으로 동작).
"""

import argparse
import os
import sys

# ---- 스캐너 유틸 (주석/문자열 상태 유지) ----
def _is_ident_char(c):
    return c.isalnum() or c in "_$"

def _word_at(s, i, word):
    n = len(s)
    w = len(word)
    if i + w > n:
        return False
    if s[i:i+w] != word:
        return False
    # Verilog는 소문자 'module'만 키워드로 취급 (대소문자 구분)
    # 토큰 경계 확인
    prev_ok = (i == 0) or not (_is_ident_char(s[i-1]) or s[i-1] == '\\')
    next_ok = (i + w == n) or not (_is_ident_char(s[i+w]) or s[i+w] == '\\')
    return prev_ok and next_ok

def _read_module_name(s, i_after_module):
    """
    i_after_module: 'module' 키워드 직후 인덱스.
    반환: (name, j)  where name은 비교용 정규화 이름(escape면 앞의 '\' 제거), j는 읽기 종료 인덱스.
    """
    n = len(s)
    j = i_after_module
    # 공백 스킵
    while j < n and s[j].isspace():
        j += 1
    # SystemVerilog 'automatic' 지원(있으면 스킵)
    if s.startswith("automatic", j) and _word_at(s, j, "automatic"):
        j += len("automatic")
        while j < n and s[j].isspace():
            j += 1
    # escape 식별자 (\name<space>)
    if j < n and s[j] == '\\':
        j += 1
        start = j
        # 공백 전까지가 이름
        while j < n and not s[j].isspace():
            j += 1
        raw = s[start:j]
        name = raw  # 비교용으로는 백슬래시 제거한 이름 사용
        return (name, j)
    # 일반 식별자
    if j < n and (s[j].isalpha() or s[j] == '_'):
        start = j
        j += 1
        while j < n and _is_ident_char(s[j]):
            j += 1
        name = s[start:j]
        return (name, j)
    # 이름을 못 읽음
    return (None, j)

def find_module_span(text, target_name):
    """
    text에서 target_name 모듈의 [start_idx, end_idx) 범위를 반환.
    - 주석(/* */, //)과 문자열("...") 내부의 키워드는 무시.
    - end_idx는 'endmodule'가 속한 줄의 끝(개행 포함)까지로 확장하여 원문 보존.
    """
    n = len(text)
    i = 0
    in_sl = False  # // ...
    in_ml = False  # /* ... */
    in_str = False # "..."
    while i < n:
        ch = text[i]
        # 문자열 토글(escape 고려)
        if not in_sl and not in_ml:
            if ch == '"':
                # 이전 백슬래시 연속 수로 escape 여부 판단
                backslashes = 0
                k = i - 1
                while k >= 0 and text[k] == '\\':
                    backslashes += 1
                    k -= 1
                if backslashes % 2 == 0:
                    in_str = not in_str
                i += 1
                continue
        # 한줄 주석 시작
        if not in_str and not in_ml and ch == '/' and i + 1 < n and text[i+1] == '/':
            in_sl = True
            i += 2
            continue
        # 블록 주석 시작
        if not in_str and not in_sl and ch == '/' and i + 1 < n and text[i+1] == '*':
            in_ml = True
            i += 2
            continue
        # 한줄 주석 종료
        if in_sl:
            if ch == '\n':
                in_sl = False
            i += 1
            continue
        # 블록 주석 종료
        if in_ml:
            if ch == '*' and i + 1 < n and text[i+1] == '/':
                in_ml = False
                i += 2
            else:
                i += 1
            continue
        # 문자열 내부
        if in_str:
            i += 1
            continue

        # 주석/문자열 바깥: 'module' 탐지
        if _word_at(text, i, "module"):
            start_idx = i
            # 모듈명 읽기
            name, j = _read_module_name(text, i + len("module"))
            if name is not None:
                # escape 식별자 비교를 위해 target_name과 동일하게 비교
                if name == target_name:
                    # endmodule까지 스캔
                    k = j
                    depth = 1
                    in_sl2 = in_ml2 = in_str2 = False
                    while k < n:
                        c = text[k]
                        # 문자열 토글
                        if not in_sl2 and not in_ml2:
                            if c == '"':
                                backslashes = 0
                                t = k - 1
                                while t >= 0 and text[t] == '\\':
                                    backslashes += 1
                                    t -= 1
                                if backslashes % 2 == 0:
                                    in_str2 = not in_str2
                                k += 1
                                continue
                        # // 시작
                        if not in_str2 and not in_ml2 and c == '/' and k + 1 < n and text[k+1] == '/':
                            in_sl2 = True
                            k += 2
                            continue
                        # /* 시작
                        if not in_str2 and not in_sl2 and c == '/' and k + 1 < n and text[k+1] == '*':
                            in_ml2 = True
                            k += 2
                            continue
                        # // 종료(개행)
                        if in_sl2:
                            if c == '\n':
                                in_sl2 = False
                            k += 1
                            continue
                        # /* 종료
                        if in_ml2:
                            if c == '*' and k + 1 < n and text[k+1] == '/':
                                in_ml2 = False
                                k += 2
                            else:
                                k += 1
                            continue
                        # 문자열 내부
                        if in_str2:
                            k += 1
                            continue
                        # 토큰 검사
                        if _word_at(text, k, "module"):
                            depth += 1
                            k += len("module")
                            continue
                        if _word_at(text, k, "endmodule"):
                            depth -= 1
                            k += len("endmodule")
                            if depth == 0:
                                # 라인 끝까지 포함(레이블/코멘트 보존)
                                while k < n and text[k] != '\n':
                                    k += 1
                                if k < n:
                                    k += 1  # 개행 포함
                                end_idx = k
                                return (start_idx, end_idx)
                            continue
                        k += 1
            # 이름 불일치면 그냥 스킵
        i += 1
    raise ValueError(f"Module '{target_name}' not found.")

def sanity_check(text, target_name):
    # 모듈 한 개만 있어야 함
    count_module = 0
    i = 0
    n = len(text)
    in_sl = in_ml = in_str = False
    while i < n:
        ch = text[i]
        # 문자열/주석 토글(간단판)
        if not in_sl and not in_ml and ch == '"':
            in_str = not in_str
            i += 1
            continue
        if not in_str and not in_ml and ch == '/' and i + 1 < n and text[i+1] == '/':
            in_sl = True; i += 2; continue
        if in_sl:
            if ch == '\n':
                in_sl = False
            i += 1; continue
        if not in_str and not in_sl and ch == '/' and i + 1 < n and text[i+1] == '*':
            in_ml = True; i += 2; continue
        if in_ml:
            if ch == '*' and i + 1 < n and text[i+1] == '/':
                in_ml = False; i += 2; continue
            i += 1; continue
        if in_str:
            i += 1; continue
        if _word_at(text, i, "module"):
            count_module += 1
            i += len("module")
            continue
        i += 1
    if count_module != 1:
        raise AssertionError(f"extracted text contains {count_module} module tokens (expected 1).")
    # 시작/끝 키워드 존재
    if "endmodule" not in text:
        raise AssertionError("no 'endmodule' in output.")
    if not text.lstrip().startswith("module"):
        raise AssertionError("output does not start with 'module'.")

def main():
    p = argparse.ArgumentParser(description="Extract a Verilog module block without preprocessing (preserve original).")
    p.add_argument("input", help="Input Verilog file")
    p.add_argument("module", help="Target module name (escaped name: pass without leading backslash)")
    p.add_argument("-o", "--output", help="Output file (default: <module>.v)")
    p.add_argument("--verbose", action="store_true", help="Print step checks")
    args = p.parse_args()

    in_path = os.path.abspath(args.input)
    if not os.path.isfile(in_path):
        print(f"[error] input not found: {in_path}", file=sys.stderr)
        sys.exit(1)
    out_path = os.path.abspath(args.output if args.output else f"{args.module}.v")

    # 1) 입력 파악
    if args.verbose:
        print(f"[check-1] input='{in_path}', target='{args.module}', out='{out_path}'")

    with open(in_path, "r", encoding="utf-8", errors="ignore") as f:
        text = f.read()

    # 2) 경계 탐지 (전처리/주석 제거 없음)
    try:
        start, end = find_module_span(text, args.module)
    except Exception as e:
        print(f"[error] cannot locate module: {e}", file=sys.stderr)
        sys.exit(2)

    if args.verbose:
        print(f"[check-2] span=({start}, {end}) length={end-start} chars")

    # 3) 추출
    out_text = text[start:end]

    # 간단 검증
    try:
        sanity_check(out_text, args.module)
        if args.verbose:
            print("[check-3] output has exactly one module block and ends with 'endmodule'.")
    except AssertionError as e:
        print(f"[error] sanity check failed: {e}", file=sys.stderr)
        sys.exit(3)

    # 4) 저장
    with open(out_path, "w", encoding="utf-8") as f:
        f.write(out_text)

    if args.verbose:
        print(f"[check-4] wrote '{out_path}' ({len(out_text)} bytes)")

if __name__ == "__main__":
    main()

    사용 예

    # 모듈 블록만 그대로 추출하여 my_block.v 생성
python extract_verilog_module_raw.py chip_top_netlist.v my_block --verbose

# 출력 파일명 지정
python extract_verilog_module_raw.py chip_top_netlist.v dma_core -o dma_core_only.v

    간단 검증 포인트(요약)

    • [check-1] 인자 파싱: 경로/모듈명/출력명 확인 → 입력 파악 OK

    • [check-2] 경계 좌표/길이 출력 → 정상적으로 경계 인식 여부 확인

    • [check-3] 추출물 내 module 1개, endmodule 존재 → “모듈만 포함” 확인

    • [check-4] 파일 기록 바이트 수 → 저장 확인

    구현 메모

    • 전처리/치환 없음: 헤더의 ``define, timescale 등은 이동하지 않습니다. 모듈 내부에 있는 지시문은 그대로 따라붙습니다.

    • 모듈명이 escape 식별자(예: \foo.bar/baz )인 경우, 호출 시 foo.bar/baz처럼 백슬래시 없이 전달하면 인식됩니다(코드에서 비교 시 백슬래시를 제거함).

    • 드문 케이스로 중첩 module 키워드가 파일 내 등장할 수 있어 깊이 카운터를 두었지만, 일반 Verilog에서는 중첩 모듈 정의는 허용되지 않습니다(보수적 안전장치).

    필요하면, “모듈만”이 아닌 파일 상단 배너 주석/timescale/default_nettype 같은 라인도 함께 복사하는 옵션을 추가해 드릴 수 있어요.
