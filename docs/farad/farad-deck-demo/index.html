    Farad 아티팩트 덱 템플릿 — Confluence 페이지 안에서 바로 발표하는 HTML 슬라이드

    아래는 Farad의 farad-artifact 스킬에 새로 추가한 슬라이드 덱 템플릿을 그대로 붙여 넣은 것이다. 원래 목적지는 Confluence Data Center의 HTML 매크로지만, 호스트 CSS를 견디도록 만들어서 이 블로그에서도 똑같이 동작한다.

    보는 법:

    • 페이지에서는 슬라이드가 세로로 쌓인 스택으로 읽힌다.
    • 오른쪽 위 Present를 누르면 전체화면 발표 모드로 바뀐다. ← → 로 넘기고 Esc 로 나온다.
    • 창을 좁히면 680px 아래에서 16:9를 풀고 읽히는 카드로 바뀐다.

    Farad 아티팩트 · 덱 라우트 데모

    Confluence 페이지 안에서 발표하기

    pptx를 첨부하는 대신, 슬라이드를 페이지에 그대로 붙이고 거기서 전체화면으로 발표한다.

    1

    에이전트는 pptx보다 HTML을 훨씬 잘 만든다

    • HTML은 렌더해서 스스로 확인하고 고칠 수 있다. pptx는 EMU 좌표를 눈 감고 찍는 작업이다
    • flex·grid는 내용이 늘어나면 알아서 밀린다. pptx는 한글 12pt가 몇 줄인지 폰트 메트릭으로 추정해야 한다
    • 학습 데이터의 양이 비교가 안 된다

    2

    목적지가 형식을 정한다

    웹 덱

    컨플루언스에 올리거나 그냥 발표만 하면 된다. 링크 하나로 끝나고 항상 최신이다.

    PPTX

    받는 사람이 PowerPoint에서 직접 고쳐야 하거나, 사내 마스터 템플릿 심의를 타야 할 때.

    3

    실패 모드가 다르다

    내용이 넘칠 때 PPTX 이 덱
    결과 조용히 잘림 슬라이드가 길어짐
    만든 사람이 아는가 열어보기 전엔 모름 한눈에 보임
    화면 크기 대응 고정 폭에 비례해 스케일

    4

    비율은 슬라이드가 아니라 빈 칸이 담당한다

    • aspect-ratio를 슬라이드에 직접 주면 block 축 min-content가 비율에서 전이된 값이 된다 — 넘친 내용이 다음 슬라이드를 침범한다
    • 그래서 비율은 빈 그리드 아이템이 갖고, 내용과 같은 셀에 겹친다
    • 행 높이 = 둘 중 큰 쪽. 평소엔 16:9, 넘치면 길어진다

    5

    JS가 없어도 내용은 그대로 읽힌다

    • 스케일은 컨테이너 쿼리 단위라 CSS만으로 동작한다
    • JS는 전체화면·키보드·카운터만 얹는다. 관리자가 HTML 매크로를 끄거나 사이트가 스크립트를 걸러도 슬라이드 스택으로 남는다
    • 키보드는 document가 아니라 덱에만 바인딩한다 — 안 그러면 Confluence 단축키를 가로챈다

    6

    위의 Present를 눌러 보세요

    전체화면으로 바뀌고 ← → 로 넘어갑니다. Esc로 빠져나옵니다.

    7

    1 / 7

    설계 메모

    슬라이드 폭에 비례해 글자가 커지는 것은 컨테이너 쿼리 단위(cqw) 하나로 처리했다. JS로 transform: scale()을 계산하는 reveal.js 방식이 아니라, 스케일 자체가 CSS라서 스크립트가 없어도 레이아웃이 성립한다.

    한 가지 함정이 있었다. 슬라이드에 aspect-ratio: 16 / 9를 직접 주면, 폭이 확정된 상자의 block 축 min-content 크기가 비율에서 전이된 값으로 결정된다. 그래서 min-height: min-content를 붙여도 상자가 자라지 않고, 넘친 내용이 박스 밖으로 흘러 다음 슬라이드를 덮어썼다. 비율을 빈 그리드 아이템에 옮기고 내용과 같은 셀에 겹치니 행 높이가 둘 중 큰 쪽이 되어, 평소에는 16:9이고 내용이 넘치면 슬라이드가 길어진다. 생성된 PowerPoint가 조용히 글자를 잘라먹는 것과 정확히 반대되는 동작이다.

    컨테이너 타입을 size가 아니라 inline-size로 둔 것도 같은 이유다. size는 블록 축까지 containment를 걸어 높이가 내용과 무관해지므로, 잘림이 그대로 돌아온다.
