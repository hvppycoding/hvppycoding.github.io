farad-artifact border·strong-border 토큰 값 비교

세 템플릿이 이 토큰을 쓰는 곳(섹션 제목 밑줄, 표, 인용, 노트, 구분선, 덱 비교·스택·흐름도, chart_svg.py 차트, SVG 다이어그램, 푸터)을 템플릿 CSS 규칙대로 그리고 선 토큰 값만 바꿨습니다. 새 색은 만들지 않고 모두 Farad 앱 팔레트에 있는 회색을 썼습니다. 순서는 divider → border → strong-border로 항상 뒤가 진합니다.
