    간단한 notice 애플리케이션

    2025-08-08

    데스크탑 환경에서 notice pop-up을 위한 조그많고 간단한 애플리케이션을 만들고 싶어. notice는 python mkdocs 패키지를 이용해서 local file 배포가 가능한 web으로 제작될거라서 가운데는 web viewer가 있어야해. 시작 커맨드는 simple_notice path/to/index.html 로 하면 될 것 같아. 애플리케이션이 열리면 가장 위에 떠야해. 그리고 제일 아래에는 “7일간 다시 열지 않음” 버튼과 닫기 버튼이 있어야해. “7일간 다시 열지 않음”을 선택했으면 유저 홈디렉토리의 .config 같은 곳에 해당 파일의 경로와 버튼을 누른 시간을 저장해서 실제로 7일간은 뜨지 않아야해

    좋아요—요구사항 깔끔하네요.
    한 줄 요약: simple_notice <path/to/index.html>로 실행하면 항상 맨 위에 뜨는 작은 창에 로컬 HTML을 WebView로 띄우고, 아래에 “7일간 다시 열지 않음” / 닫기 버튼. “7일간…”을 누르면 유저 설정 디렉토리에 해당 파일 경로와 시간을 저장해 7일 동안 자동으로 안 뜨도록.

    아래 순서대로 진행하면 됩니다.

    1) 전체 설계 (step-by-step)

    1. CLI 인자 파싱 : simple_notice path/to/index.html.

    2. 스누즈 체크 : ~/.config/simple_notice/prefs.json(플랫폼별 안전 경로는 platformdirs로 확보)에 { "absolute_html_path": "ISO시간" } 형태 저장.

      • 실행 시 해당 경로의 저장 시간이 지금-저장 ≥ 7일 이면 표시, 아니면 즉시 종료.

    3. UI : PySide6(=Qt6) + QtWebEngine 사용

      • 중앙: QWebEngineView로 file:///.../index.html 로드

      • 하단: 버튼 2개(“7일간 다시 열지 않음”, “닫기”)

      • 창 옵션: 항상 위(WindowStaysOnTopHint), 적당한 기본 크기(예: 900×600), 리사이즈 가능

    4. 동작 :

      • “7일간 다시 열지 않음” 클릭 → 현재 시각 저장 후 창 닫기

      • “닫기” → 저장 없이 닫기

    5. 배포 : pyproject.toml에 콘솔 스크립트 엔트리 simple_notice 등록(전역 실행용).

    2) 필요한 패키지

    • PySide6 (Qt 및 WebEngine 포함)

    • platformdirs (플랫폼별 설정 경로)

    pip install PySide6 platformdirs

    3) 최소 실행 가능한 코드

    아래 두 파일만으로 동작합니다. (원하면 나중에 패키징 단계 참고)

    simple_notice/__main__.py

    import sys
import json
from datetime import datetime, timedelta, timezone
from pathlib import Path

from platformdirs import user_config_dir

from PySide6.QtCore import QUrl, Qt
from PySide6.QtWidgets import (
    QApplication, QWidget, QVBoxLayout, QHBoxLayout, QPushButton, QMessageBox
)
from PySide6.QtWebEngineWidgets import QWebEngineView

APP_NAME = "simple_notice"
ORG_NAME = "local"  # 원하면 회사/조직명으로 변경
SNOOZE_DAYS = 7

def config_file_path():
    cfg_dir = Path(user_config_dir(APP_NAME, ORG_NAME))
    cfg_dir.mkdir(parents=True, exist_ok=True)
    return cfg_dir / "prefs.json"

def load_prefs():
    p = config_file_path()
    if p.exists():
        try:
            return json.loads(p.read_text(encoding="utf-8"))
        except Exception:
            # 손상시 초기화
            return {}
    return {}

def save_prefs(prefs: dict):
    config_file_path().write_text(json.dumps(prefs, ensure_ascii=False, indent=2), encoding="utf-8")

def should_skip(abs_html_path: str) -> bool:
    prefs = load_prefs()
    iso = prefs.get(abs_html_path)
    if not iso:
        return False
    try:
        saved = datetime.fromisoformat(iso)
    except Exception:
        return False
    return datetime.now(timezone.utc) - saved < timedelta(days=SNOOZE_DAYS)

class NoticeWindow(QWidget):
    def __init__(self, html_path: Path):
        super().__init__()
        self.html_path = html_path

        self.setWindowTitle("Notice")
        # 항상 위
        self.setWindowFlag(Qt.WindowStaysOnTopHint, True)
        self.resize(900, 600)

        layout = QVBoxLayout(self)

        # Web view
        self.view = QWebEngineView(self)
        self.view.setUrl(QUrl.fromLocalFile(str(self.html_path)))
        layout.addWidget(self.view, stretch=1)

        # Buttons
        btn_row = QHBoxLayout()
        self.btn_snooze = QPushButton("7일간 다시 열지 않음")
        self.btn_close = QPushButton("닫기")
        btn_row.addStretch(1)
        btn_row.addWidget(self.btn_snooze)
        btn_row.addWidget(self.btn_close)
        layout.addLayout(btn_row)

        self.btn_snooze.clicked.connect(self.snooze_and_close)
        self.btn_close.clicked.connect(self.close)

    def snooze_and_close(self):
        prefs = load_prefs()
        prefs[str(self.html_path)] = datetime.now(timezone.utc).isoformat()
        save_prefs(prefs)
        self.close()

def main(argv=None):
    argv = argv or sys.argv[1:]
    if len(argv) != 1:
        print("Usage: simple_notice /absolute/or/relative/path/to/index.html", file=sys.stderr)
        sys.exit(2)

    html_path = Path(argv[0]).expanduser().resolve()
    if not html_path.exists():
        print(f"HTML not found: {html_path}", file=sys.stderr)
        sys.exit(1)

    # 스누즈 체크
    if should_skip(str(html_path)):
        # 조용히 종료 (필요하면 메시지 출력 가능)
        sys.exit(0)

    # Qt 앱 실행
    app = QApplication(sys.argv)
    win = NoticeWindow(html_path)
    win.show()
    sys.exit(app.exec())

if __name__ == "__main__":
    main()

    4) 사용 방법

    1. (선택) 패키지로 설치
    pip install -e .

    전역으로 쓰려면 pipx install . 추천

    1. 실행
    simple_notice path/to/index.html

    • 창은 항상 최상단에 뜹니다.

    • “7일간 다시 열지 않음”을 누르면 해당 HTML 경로 기준으로 7일 동안 자동 표시 차단됩니다.

      • 설정 저장 위치(예):

        • Linux: ~/.config/simple_notice/prefs.json

        • macOS: ~/Library/Application Support/simple_notice/prefs.json

        • Windows: %APPDATA%\simple_notice\prefs.json

    5) 자잘한 옵션/개선 아이디어 (필요 시)

    • 강제 표시 플래그 : --force 추가해서 스누즈 무시하고 띄우기

    • 창 크기/제목 설정 : 인자로 --title, --width, --height

    • 여러 공지 관리 : --key some-id로 같은 파일이라도 서로 다른 정책 적용

    • 종료 시각 표시 : 버튼 클릭 시 “YYYY-MM-DD까지 표시 안 함” 토스트 안내

    필요하다면 위 코드에 원하는 옵션들 바로 얹어드릴게요. 먼저 이대로 만들어보고, OS 환경(Windows/macOS/Linux) 알려주시면 경로/배포 방식도 딱 맞게 손봐드리겠습니다.

    mkdocs로는 파이썬으로 만들고 최종적으로는 만들어진 _site 경로만 열면 돼서 이거 때문에 파이썬으로 할 필요는 없어. 그냥 내가 말한 스펙을 달성하기 위해 최선의 선택을 하면 돼. 이런 일을 하는 오픈소스나 잘 알려진 프로그램이 있나 알아봐줘. 바퀴를 두 번 발명할 필요는 없으니까

    “바퀴를 다시 발명”하는 대신, 최대한 간단히 원하는 기능을 제공하는 기존 오픈소스 도구 를 활용하는 방법을 정리해봤어요.

    가능한 접근 방식 (오픈소스/준비된 솔루션)

    1. Electron 기반으로 직접 구현하기

    • Electron은 Node.js + Chromium 기반의 데스크탑 앱 개발 플랫폼입니다.

    • 로컬 HTML 파일을 띄우는 데 적합하며, 다음과 같은 사항 구현이 용이합니다:

      • 항상 위에 띄우기 (alwaysOnTop: true 옵션 활용)

      • 하단 버튼 영역 추가 (HTML/CSS/JS로 자체 제작)

      • 7일간 다시 열지 않기 기능 (로컬 스토리지나 파일 저장을 통해 가능)

    • 즉, 직접 개발하되 이미 갖춰진 GUI 프레임워크를 활용해서 구현 부담을 크게 줄일 수 있어요.

    2. "Go-to-Sleep" 팝업 스크립트 (macOS 기반 스크립트)

    • eieio.games 블로그에 나온 macOS용 알림 스크립트 예시: 시스템 스케줄 기반으로 always-on-top 팝업 띄우고 snooze 기능을 구현한 스크립트가 있어요 Google GroupsJavaScript in Plain English+6eieio.games.

    • 브라우저 기반은 아니지만, UI 방식과 snooze 로직에서 영감을 얻을 수 있습니다.

    3. 파워토이즈 (PowerToys)의 Always on Top 기능

    • Windows에서는 Microsoft PowerToys 에 Always on top 기능만 실행하면, 선택한 창을 단축키로 최상단에 고정할 수 있어요 Reddit.

    • 웹뷰 + snooze 로직만 따로 구현해서 이 기능과 조합할 수도 있습니다.

    모든 플랫폼에서 동작했으면 좋겠어. 사용하려는 환경은 리눅스 환경이야

    그렇다면 상황이 조금 더 명확해졌네요.
    결론부터 말씀드리면 , 말씀하신 기능을 “그대로” 제공하는 크로스플랫폼(Windows/macOS/Linux) 완성품은 없고, 비슷한 건 있어도 HTML 표시 + always-on-top + 7일 snooze를 다 만족하진 않습니다.
    그래서 현실적으로는 가벼운 크로스플랫폼 프레임워크로 직접 제작하는 게 최선 입니다.

    왜 기존 완제품이 없는가?

    • 알림/팝업 앱은 많지만, 대부분 OS 알림 API 를 이용하기 때문에 HTML 뷰어/버튼 UI를 내장하지 않음.

    • 로컬 HTML을 직접 보여주는 기능이 있는 앱은 브라우저/뷰어 계열인데, snooze 같은 사용자별 일정 로직을 제공하진 않음.

    • always-on-top 기능은 일부 있지만, 환경별로 구현이 다르기 때문에 범용 제품에서 통합 제공 사례가 거의 없음.

    크로스플랫폼(Linux 포함) 최적 접근

    1. Electron

    • Node.js + Chromium 기반 → HTML 그대로 띄울 수 있음.

    • 모든 주요 OS 지원.

    • always-on-top 윈도 속성(alwaysOnTop: true) 제공.

    • snooze 로직은 ~/.config/simple_notice 같은 경로에 JSON 저장으로 구현 가능.

    • 단점: 앱 용량이 커짐(수십 MB), Node.js 필요.

    2. Tauri

    • Rust + WebView 기반 → Electron보다 훨씬 가벼움(수 MB).

    • 모든 주요 OS 지원.

    • 로컬 HTML 로드, always-on-top 지원.

    • snooze 로직도 가능.

    • 단점: Rust toolchain 설치 필요.

    3. PySide6 / PyQt6 + QtWebEngine

    • Python 기반, HTML WebView 내장 가능.

    • Qt에서 always-on-top 속성 제공.

    • Linux 배포 시 PyInstaller로 하나의 실행 파일로 패키징 가능.

    • 단점: 배포 파일 크기 Electron보단 작지만 여전히 수십 MB 수준.

    오케이, “알림”이 아니라 유저 가이드(로컬 HTML) 를 띄우는 용도군요.
    결론: 딱 이 목적에 맞춰 이미 배포된 “완제품”은 거의 없고, 리눅스에선 YAD , 크로스플랫폼까지 보려면 Nativefier 가 제일 현실적입니다. 둘 다 설치만 하면 바로 써먹을 수 있어서 바퀴를 다시 만들 필요가 거의 없어요.

    리눅스에서 바로 쓰는 최단경로: YAD

    YAD는 GTK 기반 대화상자 툴인데, HTML을 WebKit으로 렌더링 하고, 버튼을 하단에 붙이고 , 창을 “항상 위”로 띄우는 옵션을 다 갖고 있어요.

    • HTML 렌더링/브라우저 모드: --html --browser yad-guide.ingk.se

    • 하단 버튼 추가: --button= 옵션 (레이블/아이콘/툴팁/커맨드 지정 가능) yad-guide.ingk.se

    • 항상 위: --on-top 옵션 지원 man.archlinux.org

    예시 (당장 실행)

    yad --html --browser \
    --uri="file:///absolute/path/to/_site/index.html" \
    --width=900 --height=600 --on-top \
    --buttons-layout=end \
    --button="7일간 다시 열지 않음:snooze" \
    --button="닫기:1"

    --button="라벨:ID"에서 ID에 숫자 를 넣으면 종료 코드가 되고, 문자열 을 넣으면 그 문자열 커맨드를 실행(닫히지 않음)하게 만들 수 있어요. 그래서 snooze 같은 커맨드명과 함께 간단한 래퍼 스크립트로 7일 스누즈 를 구현하면 됩니다. yad-guide.ingk.se

    7일 스누즈(경량 래퍼)

    • ~/.config/simple_notice/prefs.json에 HTML 경로 → 저장시각 을 기록하고,

    • 실행 시 “지금−저장시각 < 7일”이면 그냥 종료 , 아니면 yad 실행.

    • YAD 버튼의 snooze 커맨드는 “현재 시각 저장 후 창 닫기”만 하면 끝.

    YAD는 배포판에 따라 HTML 옵션이 WebKit 빌드 여부에 의존합니다. 일반적인 배포판에선 --html이 포함된 YAD 패키지를 제공합니다(미포함이면 WebKit 빌드가 필요). 매뉴얼/가이드 참고. manpages.ubuntu.comman.archlinux.orgLaunchpad

    크로스플랫폼(Win/macOS/Linux)까지: Nativefier

    Nativefier는 아무 웹페이지든 데스크탑 앱으로 포장 해주는 툴입니다. Electron 기반이라 항상 위(--always-on-top)도 지원하고, Linux/Windows/macOS 다 됩니다. GitHub+1

    • file:///path/to/_site/index.html 같은 로컬 파일 도 포장 가능(이슈/사례 다수). GitHub

    • 명령 예: 
      nativefier "file:///absolute/path/to/_site/index.html" \
  --name "SimpleNotice" --always-on-top --width 900 --height 600

    • 7일 스누즈 는 Nativefier 자체 기능은 없으니,

      • (간단) 런처 스크립트에서 시간 체크 후 앱 실행

      • (고급) --inject로 JS/CSS를 주입해 하단 버튼 UI 를 덧입히고, 스누즈 버튼 클릭 시 로컬 설정(파일)을 갱신 → 다음 실행 때 런처가 체크
        이런 식으로 쉽게 붙일 수 있어요. todesktop.com

from platformdirs import user_config_dir

APP_NAME = "simple_notice"
ORG_NAME = "local"
SNOOZE_DAYS = 7

def config_file_path() -> Path:
    cfg_dir = Path(user_config_dir(APP_NAME, ORG_NAME))
    cfg_dir.mkdir(parents=True, exist_ok=True)
    return cfg_dir / "prefs.json"

def load_prefs() -> dict:
    p = config_file_path()
    if p.exists():
        try:
            return json.loads(p.read_text(encoding="utf-8"))
        except Exception:
            return {}
    return {}

def save_prefs(prefs: dict) -> None:
    config_file_path().write_text(json.dumps(prefs, ensure_ascii=False, indent=2), encoding="utf-8")

def should_skip(abs_html_path: str) -> bool:
    prefs = load_prefs()
    iso = prefs.get(abs_html_path)
    if not iso:
        return False
    try:
        saved = datetime.fromisoformat(iso)
    except Exception:
        return False
    return datetime.now(timezone.utc) - saved < timedelta(days=SNOOZE_DAYS)

    def __init__(self, html_path: Path, width=900, height=600, title="User Guide"):
        super().__init__()
        self.html_path = html_path

        self.setWindowTitle(title)
        self.setWindowFlag(Qt.WindowStaysOnTopHint, True)  # 항상 위
        self.resize(width, height)

        root = QVBoxLayout(self)

        # 중앙 WebView
        self.view = QWebEngineView(self)
        self.view.setUrl(QUrl.fromLocalFile(str(self.html_path)))
        root.addWidget(self.view, stretch=1)

        # 하단 버튼
        row = QHBoxLayout()
        btn_snooze = QPushButton("7일간 다시 열지 않음")
        btn_close = QPushButton("닫기")
        row.addStretch(1)
        row.addWidget(btn_snooze)
        row.addWidget(btn_close)
        root.addLayout(row)

        btn_snooze.clicked.connect(self.snooze_and_close)
        btn_close.clicked.connect(self.close)

    def snooze_and_close(self):
        prefs = load_prefs()
        prefs[str(self.html_path)] = datetime.now(timezone.utc).isoformat()
        save_prefs(prefs)
        self.close()

def main(argv=None):
    argv = argv or sys.argv[1:]
    if len(argv) != 1:
        print("Usage: simple_notice_qt5 /absolute/or/relative/path/to/index.html", file=sys.stderr)
        sys.exit(2)

    html_path = Path(argv[0]).expanduser().resolve()
    if not html_path.exists():
        print(f"HTML not found: {html_path}", file=sys.stderr)
        sys.exit(1)

    if should_skip(str(html_path)):
        sys.exit(0)

    app = QApplication(sys.argv)
    win = NoticeWindow(html_path)
    win.show()
    sys.exit(app.exec_())

if __name__ == "__main__":
    main()
