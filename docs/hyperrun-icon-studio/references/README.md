# Adobe reference icon catalog

Thirteen original SVG assets are bundled for offline visual comparison: Photoshop,
Illustrator, InDesign, Premiere Pro, After Effects and Lightroom in two documented
generations, plus the retained Photoshop CC2015 icon. These are reference images,
separate from generated HyperRun icons; no reference artwork enters design JSON or
SVG/PNG exports. Product names and marks belong to Adobe. No endorsement is implied.

Retrieved/verified **2026-10-11 (Asia/Seoul)**. Existing `illustrator-cc.svg` and
`photoshop-cc-2015.svg` are preserved byte-for-byte. Every downloaded file matches its
Wikimedia imageinfo SHA-1; the immutable local SHA-256 values are recorded below.
SVG viewBoxes are reported from the actual XML rather than Commons preview dimensions.

## Generation evidence

- **Classic**: the Photoshop CC2015 file page identifies version16 (2015). Its current
  SVG upload is from 2026, which is a file maintenance date, not the design’s era.
- **Before 2025**: file histories document the 2020 redesign and subsequent cleanups.
  Illustrator uses the archived 2022-08-14 upload rather than the current 2025 file.
  Photoshop’s page summary still says2019 and Lightroom’s still says2018; their actual
  histories explicitly identify newer uploads on2020-06-16. Those history records,
  rather than stale description dates, support the catalog’s2020 labels.
- **2025-plus**: [Adobe Design’s explanation](https://adobe.design/ideas/behind-the-design-adobe-s-updated-app-icons)
  places the revised mnemonic system’s rollout at Adobe MAX2025. Each included Commons
  CC2026 page dates its design to2025-10-28; Illustrator’s current file history identifies
  the2025-10-29 upload as the CC2026 logo update. The application release nameCC2026
  is therefore not mistaken for a2026 launch date.

## Reuse information

The linked Commons pages classify these text/geometric marks as **PD-textlogo** and
identify Adobe as the source/author. That classification concerns copyright; trademark
rights remain with Adobe. The catalog provides source/revision links and original files.
After Effects’2020 page additionally supplies a **CC BY-SA4.0** option: Adobe Inc.,
with Commons upload/cleanup credited to DH93 and VulcanSphere. That SVG is unchanged;
[CC BY-SA4.0 terms](https://creativecommons.org/licenses/by-sa/4.0/) are linked here
alongside the PD-textlogo record. Commons pages describe file-specific copyright status;
the general Commons webpage text license is not represented as the SVG artwork license.

All glyphs are vector paths. XML validation found no `<text>`, embedded/raster `<image>`,
scripts, `foreignObject`, event handlers, external hrefs, font loading or CSS imports.
Local fill styles and geometric primitives are retained unchanged. The browser can use
ordinary local `img` elements with each original viewBox/aspect ratio.
