    HTML Passthrough 테스트 — 마크다운 파일 안에 순수 HTML 넣기

    이 글은 Jekyll(kramdown)이 마크다운 파일 안의 raw HTML을 그대로 통과시키는지 검증하기 위한 테스트 포스트입니다. 아래부터는 마크다운 문법 대신 HTML을 직접 썼습니다.

    커스텀 HTML 카드

    이 박스 전체는 마크다운이 아니라 <div> 블록입니다. inline style, 색상, 둥근 모서리가 그대로 렌더되면 통과입니다.

    • raw HTML 블록 통과 ✔
    • inline style 적용 ✔
    • 중첩 요소 렌더 ✔
    항목 결과
    HTML table 정상
    인라인 스타일 정상
    접고 펼치는 <details> 요소

    이 줄은 펼쳐야 보입니다 — 브라우저 네이티브 토글이 동작하는지 확인.
